# 🍕 Детское меню — Ресторан ЖАМЭЛЬ

Детское меню для ресторана **ЖАМЭЛЬ** — красочная HTML-страница в стиле настоящего ресторанного меню для детей.

## 📋 Описание

Одностраничное детское меню выполнено в сине-белой цветовой гамме с двойной рамкой по периметру и яркими детскими иллюстрациями. Помимо позиций меню, страница содержит загадки, математические задачки и раскраску для детей.

## 🚀 Использование

1. Скачайте или клонируйте репозиторий
2. Откройте файл `index.html` в любом браузере
3. Для печати нажмите **Ctrl+P** (или Cmd+P на Mac) — страница оптимизирована для печати

## 🎨 Дизайн и функционал

- **Цветовая схема:** синий (#1e3a8a) на белом фоне
- **Двойная рамка** по периметру страницы
- **Детские иллюстрации** с помощью эмодзи (рыбки, персонажи, еда)
- **Адаптивный дизайн** — корректно отображается на мобильных устройствах
- **Поддержка печати** — оптимизированные стили для вывода на принтер

### Разделы меню
| Раздел | Позиции |
|--------|---------|
| 🥗 Салаты | Фруктовый салат |
| 🍜 Супы | Суп на курином бульоне с лапшой |
| 🍕 Пицца | Пепперони, с курицей, Цезарь |
| 🍗 Горячее | Наггетсы, Картофель фри, по-деревенски |
| 🍝 Паста | Макароны с сыром |

### Интерактивные элементы для детей
- 🧩 **3 загадки** про еду с ответами
- 🧮 **Математические задачки** (6 примеров)
- 🖍️ **Блок раскраски** с предложением взять карандаши у официанта
- 🌟 **Интересные факты** о еде
